## 🛠️ Quick Start

### 1. Installation
```bash
npm install
```

### 2. Build Static Site
```bash
npm run build
```
Generates production-optimized pages in `dist/`.

### 3. Start Local Server
```bash
npm start
```
Starts local server at [http://localhost:3000](http://localhost:3000).
